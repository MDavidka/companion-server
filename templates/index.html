API Reference
developer
Base URL: — · All responses are JSON · Repository IDs must be numeric strings.
GET /api/health
Health check. Verify the server is alive and reachable.
Request
No parameters.
Response 200
{ "status": "healthy", "service": "Companion Server", "deployed_sites": 0 }
GET /api/status  ·  /api/sites
Returns all currently registered/deployed sites in the runner.
Request
No parameters.
Response 200
{ "success": true, "status": "healthy", "total": 1, "sites": [ { "name": "my-app", "port": 4501, "dir": "/srv/apps/my-app", "gitUrl": "https://github.com/u/r", "pid": 12345 } ] }
GET /api/repos
List all repositories configured across all users in MongoDB.
Request
No parameters.
Response 200
{ "success": true, "repositories": [ { "username": "MDavidka", "repo_id": "1126661988", "git_url": "https://github.com/MDavidka/tesf", "name": "tesf", "owner": "MDavidka", "full_name": "MDavidka/tesf" } ] }
GET /api/repos/:username
List repositories belonging to a single user.
URL params
username string the user document key
Response 200
{ "success": true, "username": "MDavidka", "repositories": [ ...repo objects ] }
ANY /api/deploy/:repo_id
Trigger a full deployment: pulls source from GitHub, installs deps, builds, spawns the app, and creates a Cloudflare DNS record when configured. Accepts GET or POST. No body required.
URL params
repo_id string numeric repo id (validated /^\d+$/)
Request body
None — credentials are read from MongoDB (git_url, git_token).
Response 200
{ "success": true, "message": "Deployment successful! Project: tesf", "project_name": "tesf", "url": "https://tesf.example.com", "username": "MDavidka", "repo_id": "1126661988", "dns_record_created": true }
Errors
400 Invalid repo_id format 404 Repository {repo_id} not found 404 git_token / git_url missing 500 Deployment failed (see error)
POST /api/redeploy/:name
Kill the running app process and redeploy it from the cached source.
URL params
name string project / app name from /api/status
Response 200
{ "success": true, "message": "Redeployed successfully" }
DEL /api/delete/:name
Stop the app process, remove the source directory, and unregister it.
URL params
name string project / app name
Response 200
{ "success": true, "message": "Deleted successfully" }
GET /api/logs
Retrieve recent logs from the in-memory ring buffer. Filter by project tag (usually repo_id during a deployment).
Query params
project_id string optional — filter tag (default: server) limit int optional — max lines (default 200, max 500)
Response 200
{ "success": true, "project_id": "1126661988", "logs": [ "2026-01-06 14:44:22 [INFO] [1126661988] Starting deploy..." ] }
GET /api/updater/status
Current state of the auto-updater (local vs remote commits, last check, status).
Response 200
{ "success": true, "status": "uptodate | available | checking | error", "localCommit": "a1b2c3d", "remoteCommit": "a1b2c3d", "lastChecked": "2026-05-17T10:00:00Z", "error": null }
POST /api/updater/check
Force an immediate git fetch to compare HEAD with remote. Returns the same shape as /status.
Request body
None.
POST /api/updater/update
Pull the latest commit, run npm install, and self-restart the process.
Request body
None.
Response 200
{ "success": true, "restarting": true }
